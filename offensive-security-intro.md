# Offensive Security Intro

**Platform:** TryHackMe  
**Date:** 10 August 2026  
**Difficulty:** Easy

## What I Learned
- Offensive security means thinking like an attacker to find vulnerabilities before bad guys do
- Key roles: penetration tester, red teamer, bug bounty hunter
- Hacking a fake bank (FakeBank) to find a hidden transaction

## Tools Used
- Web browser
- FakeBank web app (THM lab)

## Key Takeaway
Offensive security is legal and ethical when done on systems you have permission to test.
